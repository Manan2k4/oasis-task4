# General Knowledge Quiz

An Android multiple-choice quiz with immediate feedback and score tracking.

## Features

- Five general-knowledge questions
- Four answer choices per question
- Selected-answer state
- Correct and incorrect answer feedback
- Progress indicator
- Final score dialog
- Restart option after completion

## Built with

- Java
- Android Views and XML layouts
- Material components
- Android SDK 24+

## Run locally

1. Clone this repository.
2. Open it in Android Studio.
3. Allow Gradle to sync.
4. Run the app on an emulator or Android device.

## Project structure

`MainActivity` contains the question data and manages quiz progress, answer validation, score calculation, and the completion dialog.
